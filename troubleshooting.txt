Activity 5 - Part 2: Troubleshooting & Emergency Fixes
Name: Regidor, Arabella Grace

1. The "Oops, wrong file" Problem
Solution: git restore --staged .env

2. The "Typo in the message" Problem
Solution: git commit --amend -m "Fixed authentication typo"

3. The "Forgot a file" Problem
Solution:
git add styles.css
git commit --amend --no-edit

4. The "I hate these changes" Problem
Solution: git restore index.html

5. The "Wrong Branch" Problem
Solution:
git branch new-feature
git reset HEAD~3 --hard
git checkout new-feature

6. The "Detached HEAD" Problem
Solution: git switch -c recovery-branch

7. The "Undo a pushed mistake" Problem
Solution: git revert <buggy-commit-hash>

8. The "Accidental Deletion" Problem
Solution: git branch <deleted-branch-name> <commit-hash>

9. The "Ghost Files" Problem
Solution: git add -u

10. The "Pushed to the void" Problem
Solution: git push origin --delete testing-junk
